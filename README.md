# Django Blog Website

## Overview
This is my first Django Blog Website created using Python, Django, Bootstrap 5, and SQLite3.

## Features
- User Registration
- User Login / Logout
- User Dashboard
- Profile Edit
- Profile Image Upload
- Change Password
- Create Blog Post
- Edit Blog Post
- Delete Blog Post
- Search Blog Posts

## Technologies
- Python 3.13.14
- Django 6.0.7
- Bootstrap 5
- SQLite3
- Pillow

## Project Structure

```
home/
mysite/
media/
manage.py
requirements.txt
```

## Installation

```bash
pip install -r requirements.txt
```

```bash
py manage.py migrate
```

```bash
py manage.py runserver
```
